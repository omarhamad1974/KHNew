How do I get a token?
  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens.
  2. Choose "Only select repositories" and pick the website repository.
  3. Under Repository permissions set Contents to Read and write.
  4. Generate the token and paste it above. Treat it like a password.

The token stays in this browser and is only sent to api.github.com.
